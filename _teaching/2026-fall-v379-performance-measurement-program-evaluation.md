**Level:** Undergraduate  
**Role:** Instructor of Record  
**Semester:** Fall 2026  

### Course focus
The course introduces performance measurement and program evaluation in public affairs, including:

- Formulating evaluation questions and measuring program outcomes and performance  
- Cleaning, visualizing, and analyzing data using R  
- Randomized experiments, regression, difference-in-differences, and regression discontinuity designs  
- Distinguishing statistical associations from causal evidence  
- Using generative AI responsibly for coding and independently verifying its output  
- Communicating data analysis, causal limitations, and policy implications  

### Teaching responsibilities

- Designed the syllabus, lectures, assignments, and in-class activities  
- Led class meetings and guided hands-on data analysis in R  
- Developed assessments covering performance measurement, program evaluation, and causal inference  
- Supervised student evaluation projects and provided feedback on written and oral presentations
